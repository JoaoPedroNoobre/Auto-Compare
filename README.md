# Auto Compare

Comparador interativo de veículos desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Seleção de dois veículos
- Comparação de motor
- Potência
- Torque
- Câmbio
- Preço
- Consumo
- Desempenho
- Dimensões
- Imagens dos veículos
- Layout responsivo
- Animações durante a rolagem

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
